# Machine Learning Specialization (Coursera / DeepLearning.AI)

This repository contains my coursework and mini projects for the Machine Learning Specialization on Coursera by DeepLearning.AI. Each course folder includes Jupyter notebooks with analysis, modeling, and experiments.

## Courses

| Course | Status | Folder |
| --- | --- | --- |
| Linear Regression | Complete | Linear Regression/ |
| Logistic Regression for Classification | Ongoing | Logistic Regression for Classification/ |

## Mini projects by folder

### Linear Regression/

- 0_Analysis.ipynb - Exploratory data analysis of the medical insurance dataset.
- 1_Single_Feature.ipynb - Single-feature linear regression (age vs charges) on non-smokers.
- 2_Multiple_features.ipynb - Multi-feature linear regression (age, BMI) on non-smokers.
- 3_Categorical_features.ipynb - Encode categorical features and analyze charge relationships.
- Smoker.ipynb - Smoker-only baseline linear regression with RMSE evaluation.
- medical.csv - Medical insurance dataset used in the notebooks.

## How to use

Open any notebook in its folder and run the cells in order. The notebooks rely on common Python data science libraries (pandas, numpy, matplotlib, seaborn, scikit-learn).
