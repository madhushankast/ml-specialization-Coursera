# Linear Regression

This course folder covers foundational linear regression concepts, from exploratory analysis to single- and multi-feature models, plus handling categorical variables.

## Mini projects

- 0_Analysis.ipynb - Exploratory analysis of medical insurance data (distributions and summaries).
- 1_Single_Feature.ipynb - Single-feature linear regression for non-smokers using age.
- 2_Multiple_features.ipynb - Multi-feature linear regression for non-smokers using age and BMI.
- 3_Categorical_features.ipynb - Encode categorical variables (smoker, sex) and analyze relationships.
- Smoker.ipynb - Smoker-only baseline linear regression with RMSE evaluation.

## Dataset

- medical.csv - Medical insurance dataset used for all notebooks in this folder.
